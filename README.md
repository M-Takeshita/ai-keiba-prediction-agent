# 地方競馬予想AI — 共通版v9対応 / Codex Web検索スターター

このZIPは、ユーザー提供の原本 `prompts/地方_共通.md`（変更なし）に基づく、**役割分担設定**です。
Web検索から事前予想までのワークフロー指示を設定しますが、サイトの動的データ収集やNAR公式CSVの自動ダウンロードコードはまだありません。実レースで全頭5走や騎手統計を必ず取得できることを保証しません。

## 使い方

1. ZIPを展開し、このフォルダをVS Codeで開きます。
2. Codex VS Code拡張機能に、ChatGPT Plusでログインします。APIキーは不要です（ただしCodexの利用枠は消費します）。
3. Codexがプロジェクト内の `AGENTS.md` と `.codex/agents/*.toml` を認識できる最新版であることを確認します。
4. Codexチャットに下記を貼り付けます。

> `AGENTS.md` と `prompts/地方_共通.md` を正本として使用し、今日の開催から私が指定するレースを予想してください。`race_researcher` で実レース情報を検索し、取得データを検証したうえで、オッズを隠して `form_analyst` と `track_pace_analyst` に分析を並列委譲してください。その後、メインで能力による印を確定し、`odds_analyst` → `bet_strategy_analyst` の順に結果を得てください。指定された全頭10列表を省略せず、公式出典、取得時刻、欠損箇所を示し、情報不足なら見送ってください。`

実際に使うときは冒頭の「今日の開催から…」を「今日の園田10R」などに変更してください。開催なしの場合は勝手に別レースへ変更しない設定です。

## エージェント責務

| 名前 | 担当 | 参照するプロンプト |
|---|---|---|
| メイン | 指揮・能力順位確定・全頭10列と21項目検証 | 全文、とくに評価手順・出力形式 |
| `race_researcher` | 当日のネット情報収集と出典付与 | 調査統合・過去5走表・騎手統計 |
| `form_analyst` | 過去5走・相手/クラス・騎手評価 | ③④⑤・クラス昇降 |
| `track_pace_analyst` | コース距離・脚質・馬場・展開2案 | ②⑥⑦ |
| `odds_analyst` | 能力印を維持したオッズ/人気の相対評価 | ⑧・人気薄/危険人気/相手4番手 |
| `bet_strategy_analyst` | 本線/遊び・券種・見送り判断 | 購入額・券種・C3・最終チェック |

## データの品質
- 公式情報を優先し、各重要値には対象レース・URL・取得日時（JST）を記録してください。
- `未確認` は未取得、`－` は過去走が存在しない場合。区別してください。
- 発走済みのレースについて事後情報から「事前予想」を作らないでください。
- 公式オッズが動的表示でWeb検索から取れない場合は `未確認` とし、推測で穴埋めしないでください。
- `prompts/地方_コース別/` に開催場専用プロンプトを追加すると補助的に参照します。
- `地方競馬予想_調査レビュー_20261019.md` の原本内参照先はアップロードされていません。別途共有があれば追加してください。

## 制限と今後の開発
- このスターターは Codex の設定・プロンプト・役割定義のみ。**自動データ取得プログラム、実レースの動作保証、回収率検証機能は未実装**。
- 通常のWeb検索だけで過去5走全頭・騎手統計・直前オッズが揃わない場合、次にデータ取得アダプター（TypeScript、公式許諾されたデータ源）を開発してください。
- 並列数は3。5つのサブエージェントは全部同時に起動せず、段階的に使います。処理量とCodex利用枠が大きくなる可能性があります。
- 実際の投票・購入は行いません。

`prompts/地方_共通.md` はユーザーの添付ファイルをそのままコピーしており、役割定義の変更で原本を改変しないようにしています。
