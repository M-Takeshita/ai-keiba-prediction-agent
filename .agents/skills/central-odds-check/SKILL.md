# 中央競馬 — 最新オッズ確認だけ

1. `central/prompts/INDEX.md` の `odds_analyst` 担当ファイルを読む。
2. 対象レースと、既存の印・買い目候補があれば引き継ぐ。印がなければ順位は作らない。
3. **`odds_analyst` だけを1体起動**。JRA公式優先でオッズと出典・取得時刻・欠損を確認する。
4. 価格変動の比較は実測データがあるときだけ行う。直前オッズが取れなければ未確認とする。
5. 新たな能力順位・買い目・購入金額を決めず、別Agentを追加起動しない。
