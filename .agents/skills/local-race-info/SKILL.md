# 地方競馬 — 当日情報収集だけ

## 入力と対象
- ユーザーの指定（日付・競馬場・R）をJSTで特定する。曖昧なら対象を確認し、存在しないレースを作らない。
- 必読: `local/prompts/INDEX.md`。その中の `race_researcher` の担当モジュールを読む。

## 依頼するAgent
- **`race_researcher` のみ1体起動**し、`category=地方` と `race_key=YYYY-MM-DD|地方|場|R` を渡す。
- 公式優先のWeb検索で出馬表、全出走馬の過去5走、騎手成績、馬場情報、オッズと取得時刻、不足情報を調査するよう依頼する。

## 戻り値
- 調査事実の表、出典URL、確認時刻、未確認・未発表・取消情報。検索だけで最新値が取得できない場合はその旨記載。
- **能力順位・印・展開予想・買い目を一切作らない**。`form_analyst` 等の追加起動もしない。
- 対象レースのデータが見つからなければ未確認として止める。別レースへ無断変更しない。
