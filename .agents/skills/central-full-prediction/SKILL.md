# 中央競馬 — 総合予想（中央独自・初期ルール）

## 準備
- **`central/prompts/INDEX.md` だけ**を参照する（地方ルールは読まない）。`central/prompts/workflow/procedure.md` と `central/prompts/output/format.md` に従う。
- `YYYY-MM-DD|中央|場|R` でレースを同定。開催・発走時刻・取消を調べ、発走済みを事前予想として扱わない。
- 中央専用のユーザー独自プロンプトは未提供のため、現在は試作の初期基準であると明示する。

## 実行順
1. **`race_researcher`** でJRA公式優先の情報収集。近5走やオッズが欠けるなら未確認とする。
2. **`form_analyst` と `track_pace_analyst`** を並行起動可能。**人気とオッズを渡さず**、芝/ダート/障害、クラス、コース、馬場、展開を評価してもらう。
3. メインが事実・2者の根拠から**オッズ抜きの能力順位・仮印**を決定。不十分なら保留。
4. **`odds_analyst`** で時刻付きのオッズと印の差を調べる。価格だけで印を変更しない。
5. **`bet_strategy_analyst`** で券種・候補買い目・見送りを検討。確率や期待値を捏造しない。
6. `central/prompts/output/format.md` に従い、全頭表、根拠、情報欠損、出典と取得時刻を示す。

## 禁止
- 地方v9のC3・NAR特有のクラスや10列ルールを中央に無断適用しない。実際の投票・課金はしない。
