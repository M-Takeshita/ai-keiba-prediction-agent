# 地方競馬 — 最新オッズ確認だけ

1. `local/prompts/INDEX.md` の `odds_analyst` の担当資料を読む。
2. 対象レース、既存の確定印や候補買い目があれば入力として渡す。無ければ「未確定」とし、勝手に印を作らない。
3. **`odds_analyst` のみ1体起動**。最新公開の公式オッズを検索し、出典URL、取得時刻、馬番・馬名、未確認と変動リスクを報告する。
4. 過去データと比較できる場合だけ変動を示し、取得できない場合は「最新オッズ未取得」と記載する。
5. 予想印をオッズで変更しない。買い目金額は確定しない。追加のAgentは起動しない。
